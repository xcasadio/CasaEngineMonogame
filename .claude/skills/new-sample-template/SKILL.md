# Skill : new-sample-template

## But

Créer un sample de gameplay propre et minimal.

## Structure recommandée

- Un projet ou un dossier de sample par feature (`CasaEngine.Demos/` ou `Projects/`).
- Une scène de démarrage.
- Un README court.

## Étapes

1. Créer le squelette : init, load content, update, draw.
2. Ajouter un menu minimal, ou l'entrée dans le menu de sélection des démos s'il existe.
3. Implémenter la feature principale.
4. Ajouter les contrôles (input).
5. README : objectif, contrôles, comment lancer.

Règles propres aux samples : règle par chemin `samples`. Commits : `AGENTS.md` §4.

## Done

Sample lançable, README, build OK.
