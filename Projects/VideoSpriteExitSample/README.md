# VideoSpriteExitSample

A project with no gameplay DLL where a world video keeps playing to its end after the cutscene that started it has been left, from data alone (ADR-0132). `ExitFilmWorld.world` starts `Cutscenes/loop.cutscene` through its `startup_cutscene_asset_id` key. The project's `FirstScreenName` is empty: there is no screen.

## Objective

Show the `StartVideoSprite` action with no code of the game:

1. `ExitFilmWorld.world` holds a 2D camera (320x180 design resolution), a black clear colour, and one entity hidden at load: `clip`, whose root component is a `VideoSpriteComponent` (`video` names the catalogued clip, scale 1.5).
2. `Cutscenes/loop.cutscene` arms `ExitOnInput` (mapping `sample-input`, input `exit`, next cutscene `ExitFilmExit`), then runs an endless `Repeat`. Each lap is `StartVideoSprite` on `clip`, which shows the entity, starts the clip from its first picture and returns at once, then a `Wait` of 5 seconds. The clip lasts 4 seconds: the component hides the entity in the update where it ends, and the screen stays black for one second before the next lap starts it again.
3. `Cutscenes/exit.cutscene` dims the screen without blacking it (`FadeScreen`, subtractive, towards a grey of 128 in one second), waits 5 seconds, then runs a `ChangeWorld` to `EndWorld.world`. Leaving the loop cutscene does not touch the clip: it keeps playing under the dimmed screen until its last picture, then disappears.
4. `EndWorld.world` is a black world whose startup cutscene (`Cutscenes/end.cutscene`) waits 2 seconds, clears the overlay, then changes back to `ExitFilmWorld.world`, so the sample runs for ever.
5. `Videos/clip.mdecvideo` is the clip: 160x112 pixels, 60 frames at 15 frames per second (4 seconds), no sound, generated by `CasaEngine.Tests/Video/VideoSampleClip.cs`. It is the same file as `Projects/VideoSpriteSample/Videos/clip.mdecvideo`. `VideoSpriteExitSampleDataTests` checks it and the rest of the data.

## Controls

The `sample-input` mapping holds one input, `exit`.

| Action | Keyboard | Game pad |
|---|---|---|
| Leave: dim, the clip runs to its end, then the end world | any key | Start |

`AnyKey` reacts to each new key press, except Shift, Ctrl, Alt and Windows alone, and nothing happens while Alt or Windows is held. A key held while the cutscene starts does not trigger the exit: release it, then press a key again. After the end world the sample starts again. Close the window to quit.

## Run

From the repository root:

```bash
dotnet run --project CasaEngine.Launcher -- Projects/VideoSpriteExitSample/VideoSpriteExitSample.json
```

## What to look at

- Without a key, the clip plays, disappears, and plays again from its first picture at each lap.
- Press a key while the clip plays: the screen dims, the clip goes on under it to its last picture, then disappears; the end world follows.
- `Cutscenes/loop.cutscene`: the lap of `StartVideoSprite` and `Wait`. Compare with `Projects/VideoSpriteSample`, where `PlayVideoSprite` stops and hides the clip as soon as the exit is taken.
