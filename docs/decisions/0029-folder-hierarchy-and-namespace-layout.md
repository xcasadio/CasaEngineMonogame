# ADR-0029: Folder hierarchy and namespace layout

- **Status**: Accepted
- **Date**: 2026-09-06 (backfill)
- **Source**: `ai-agent/audits/CasaEngine_folder_hierarchy_namespace_compatibility.md:1-53`

## Context

This note documents the final state of the namespace rename after aligning the code with the physical folder hierarchy: historical or "catch-all" namespace categories were renamed to explicit segments matching the actual location of the code (`CasaEngine_folder_hierarchy_namespace_compatibility.md:1-7`). One exception is documented: the physical folders `Engine/Primitives/2D` and `Engine/Primitives/3D` keep numeric folder names but use the namespaces `Primitives.TwoD` and `Primitives.ThreeD`, because a C# namespace segment cannot start with a digit (`CasaEngine_folder_hierarchy_namespace_compatibility.md:51-53`).

## Decision

- Core: `CasaEngine.Core.Log` → `CasaEngine.Core.Logging`; `CasaEngine.Core.Maths` → `CasaEngine.Core.Math`; `CasaEngine.Core.Parser` → `CasaEngine.Core.Parsing`; `CasaEngine.Core.MultiThreading` → `CasaEngine.Core.Threading`; `CasaEngine.Core.Helpers` split into `CasaEngine.Core.Math.Extensions`, `CasaEngine.Core.Math.Geometry`, `CasaEngine.Core.Text`, `CasaEngine.Core.Time`, `CasaEngine.Core.Randomization` (source: `CasaEngine_folder_hierarchy_namespace_compatibility.md:13-21`).
- Engine: `CasaEngine.Engine.Input.InputDeviceStateProviders` → `CasaEngine.Engine.Input.Providers`; `CasaEngine.Engine.Input.InputSequence` → `CasaEngine.Engine.Input.Sequences`; `EngineEnvironment` moved from `CasaEngine.Engine` to `CasaEngine.Engine.Environment`; `CasaEngine.Engine.Primitives2D` → `CasaEngine.Engine.Primitives.TwoD`; `CasaEngine.Engine.Primitives3D` → `CasaEngine.Engine.Primitives.ThreeD` (source: `CasaEngine_folder_hierarchy_namespace_compatibility.md:25-29`).
- Framework: `CasaEngine.Framework.Game` → `CasaEngine.Framework.Application`; `CasaEngine.Framework.GameFramework` → `CasaEngine.Framework.Gameplay`; `CasaEngine.Framework.Debugger` → `CasaEngine.Framework.Debug`; `CasaEngine.Framework.GUI` → `CasaEngine.Framework.UI`; `CasaEngine.Framework.Graphics` → `CasaEngine.Framework.Rendering.Models`; `CasaEngine.Framework.Graphics2D` → `CasaEngine.Framework.Rendering.Draw2D`; `CasaEngine.Framework.World` → `CasaEngine.Framework.Scene.World`; `CasaEngine.Framework.Transform` → `CasaEngine.Framework.Scene.Transform`; `CasaEngine.Framework.Entities` → `CasaEngine.Framework.Scene.Entities`; `CasaEngine.Framework.SpacePartitioning.Octree` → `CasaEngine.Framework.Scene.Spatial.Octree`; `ObjectBase` moved from `CasaEngine.Framework` to `CasaEngine.Framework.Common`; `Constants` moved from `CasaEngine.Framework` to `CasaEngine.Framework.Configuration`; `CasaEngine.Framework.Materials` split into `CasaEngine.Framework.Materials.Runtime`, `.Definitions`, `.Authoring`, `.Compilation`, `.Serialization` (source: `CasaEngine_folder_hierarchy_namespace_compatibility.md:33-49`).
- Exception: the physical folders `Engine/Primitives/2D` and `Engine/Primitives/3D` keep numeric folder names but use the namespaces `CasaEngine.Engine.Primitives.TwoD` and `CasaEngine.Engine.Primitives.ThreeD`, since a namespace segment cannot start with a digit (source: `CasaEngine_folder_hierarchy_namespace_compatibility.md:51-53`).

## Consequences

- Most mappings are implemented and verified in the current tree: `fd`/directory checks confirm `CasaEngine/Core/Math/Extensions`, `CasaEngine/Core/Math/Geometry`, `CasaEngine/Core/Text`, `CasaEngine/Core/Time`, `CasaEngine/Core/Randomization`, `CasaEngine/Core/Logging`, `CasaEngine/Engine/Input/Providers`, `CasaEngine/Engine/Input/Sequences`, `CasaEngine/Engine/Environment`, `CasaEngine/Framework/Application`, `CasaEngine/Framework/Gameplay`, `CasaEngine/Framework/Debug`, `CasaEngine/Framework/UI`, `CasaEngine/Framework/Rendering/Models`, `CasaEngine/Framework/Rendering/Draw2D`, `CasaEngine/Framework/Scene/World`, `CasaEngine/Framework/Scene/Transform`, `CasaEngine/Framework/Scene/Entities`, `CasaEngine/Framework/Scene/Spatial`, `CasaEngine/Framework/Common`, `CasaEngine/Framework/Configuration`, `CasaEngine/Framework/Materials/{Runtime,Definitions,Authoring,Compilation,Serialization}` all exist.
- The `Primitives/2D` and `Primitives/3D` exception is verified in code: the folders keep numeric names, but files under them declare `namespace CasaEngine.Engine.Primitives.TwoD;` and `namespace CasaEngine.Engine.Primitives.ThreeD;` respectively (e.g. `CasaEngine/Engine/Primitives/2D/Primitive2D.cs:4`, `CasaEngine/Engine/Primitives/3D/PlanePrimitive.cs:3`).
- `Core.Parsing` and `Core.Threading` are **not found, unverified**: no folder or namespace matching `Core/Parsing`, `Core/Threading`, nor the pre-rename names `Core/Parser`, `Core/MultiThreading`, exist anywhere in the current tree (`fd -i "parsing|threading|multithreading|parser" CasaEngine/Core` returns nothing). The mapping's implementation status cannot be confirmed as either applied or still pending from the code alone.
