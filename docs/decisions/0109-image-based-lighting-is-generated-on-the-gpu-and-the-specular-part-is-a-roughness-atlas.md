# ADR-0109: Image-based lighting is generated on the GPU and its specular part is stored as a roughness atlas

- **Status**: Proposed
- **Date**: 2026-11-15
- **Source**: this chantier: `ai-agent/tasks/pbr-rendering-tasks.md` (arbitration P9, tasks T6.1 steps 1b and 5, T6.2, T6.3 and T7.1)

## Context

The PBR ambient needs a diffuse irradiance term and a specular term that follows the roughness. Both come from the environment cube of the world, whatever its format, and must not be computed per frame (arbitration P9).

Verified on the code and on the device (task T6.1):

- No cube of the engine has mips (`TextureCubeLoader` refuses them) and the generated cubes are `Vector4` without mips (`PanoramaEnvironmentGenerator`).
- The runtime backend is OpenGL (MonoGame DesktopGL 3.8.5.1), shader model 3.0 translated to GLSL by `mgfxc` (task T0.3).
- Step 1b of T6.1: `SAMPLE_CUBEMAP_LEVEL` was written as `texCUBElod(sampler, float4(dir, level))` under `OPENGL` (`Macros.fxh`). The compiled effect contains `textureCube(ps_s0, ...)` for it: the translation to GLSL drops the level. Measured on a cube of 128 texels per face with a full chain of 8 levels, each level a distinct solid colour (read back with `GetData`, so the levels are stored): the shader requesting the levels 0, 2 and 4 returned the colour of level 0 each time (0.1, 0.8, 0.25), not those of levels 2 (0.3, 0.6, 0.25) and 4 (0.5, 0.4, 0.25). The OpenGL chain of MonoGame ignores the requested cube level.
- Only the `D3D` variant of the macro (`SampleLevel`) honours the level, and no target of this repository uses it.

## Decision

- **Generation on the GPU, once per source, outside the view loop.** `IblCubeGenerator` draws a full-screen quad with `IblConvolution.fx` into a `Vector4` render target, reads it back with `GetData` and writes the result with `SetData`, so the generated textures do not live in render targets. It restores the render targets, the viewport and the blend, depth, rasterizer and sampler states. It never runs while a view target is bound: the caller (T6.2) runs it between views.
- **Two results.** The diffuse irradiance is a `TextureCube` of 32 texels per face, one level, `Vector4`: the cosine-weighted average of the incoming radiance (a fixed grid of 16 by 32 hemisphere samples, normalised by the sum of the weights), that is `E / pi`, so a uniform cube gives back its colour and the shader multiplies it by the diffuse albedo without a further `1 / pi`. The specular result is the atlas below.
- **The specular result is a 2D atlas, not a cube with mips.** Because the level of a cube sample is ignored on this chain (step 1b), the roughness levels cannot live in the mip chain of a cube. The prefiltered result is a `Texture2D` (`Vector4`, no mips) of 512 by 1536 texels: six latitude-longitude bands of 512 by 256 texels stacked vertically, band `n` holding the GGX-prefiltered radiance for the perceptual roughness `n / 5` (`alpha = roughness^2`; 64 importance samples with a radical-inverse sequence, `N = V = R`). Band 0 is the source resampled. The mapping inside a band is the one of `PanoramaEnvironmentGenerator.GetPanoramaUv` (`u = 0.5 + atan2(x, -z) / 2 pi`, `v = 0.5 - asin(y) / pi`, row 0 at the north pole). A band of 512 by 256 texels gives the angular resolution of a 128-texel cube face.
- **Reading the atlas (rule for T6.3 and T7.1).** A shader computes `b = roughness * 5` (the 5 is a constant of the shader, the number of bands minus one), the two bands `floor(b)` and `min(floor(b) + 1, 5)`, reads each with `tex2D` at `(u, (band + clamp(v, 0.5/256, 1 - 0.5/256)) / 6)` and interpolates linearly by `frac(b)`. The vertical coordinate is kept half a texel inside its band so that the bilinear footprint never reaches the neighbouring band. The sampler is linear, wraps in `u`, clamps in `v`, uses no mips. `IblCubeGenerator.GetAtlasUv` is the CPU twin of that mapping.
- **Colour space.** The generator takes `sourceIsLinear` (the `EnvironmentCubeIsLinear` flag of the source) and decodes every sample of a non-linear source with `pow(abs(c), 2.2)` before accumulating it. The generated textures therefore always hold linear light, whatever the colour pipeline of the view; the cache key stays the source instance, the linearity being a property of the source. The shader never reads a colour pipeline constant.
- **`SAMPLE_CUBEMAP_LEVEL` stays in `Macros.fxh`** (both variants), with a warning that the OpenGL variant ignores the level: it reads the only level of a cube without mips. The convolution uses it for level 0 inside its sample loops. A GPU test pins the step 1b outcome.
- **Sizes and cost.** Irradiance 32 texels per face; atlas 512 by 1536 in `Vector4`, 12.6 MB (no half-float variant: the plan asks for `Vector4`, and the memory stays bounded by the number of distinct source cubes). Measured on the development machine for a 128-texel source: irradiance about 14 ms, atlas about 85 ms (alert threshold of the plan: 500 ms per cube).
- **Cache (task T6.2).** `IblCache` holds, per source cube instance, the pair (irradiance cube, atlas), plus one BRDF table for all. A request is registered by `EnvironmentShaderBinder` when it binds a shader that declares the IBL parameters (`HasIbl`, `IrradianceCubeTexture`, `PrefilteredSpecularAtlasTexture`, `BrdfLookupTexture`) and finds no generated textures; a shader that does not declare them (`LitForward`) never registers anything. `RenderPipeline.Render` executes the requests at its very start (`IblCache.Flush`), before any view and with no view target bound, so the generation never runs while a view is being drawn and never inside `EnvironmentResolver.Resolve`. The request point is the binder and not the resolver because the resolved value is cached per view: a cube not yet generated would stay null in it for ever, so `ResolvedEnvironmentSettings` carries only the source cube and the binder asks the cache at every binding. The binding that follows the flush receives the textures without any change of environment (`HasIbl` goes from 0 to 1, the flat ambient being used until then, one frame). The cache is reached through `RenderFrame.Ibl` and `RenderContext.Ibl` (set by the pipeline, passed by both mesh renderers to `ShaderBindCache`, which hands it to the binder; null admitted: no request, `HasIbl` 0). The pipeline owns the cache, the generator and the BRDF table, and disposes them (`RenderPipeline.Dispose`, called from `CasaEngineGame.Dispose`).
- **Release.** At each flush, an entry whose source cube is disposed releases its irradiance and its atlas and disappears. A source that is never disposed keeps its entry until the pipeline is disposed: the memory is bounded by the number of distinct cubes of the game (12.6 MB of atlas and 0.8 MB of irradiance per cube). `GeneratedAssetHandleCache` is not the model: it never releases on the loss of the source. A generation that throws is logged once for its source, never retried, and leaves the flat ambient. Without the convolution effect (`RenderPipeline.IblCubeGenerator` null) nothing is generated and one warning is logged.
- **Counters.** `IblCache.GenerationCount` counts the generations (one per source: irradiance and atlas together) and `GeneratedOutsideViewLoop` stays true as long as none ran while the pipeline was in its view loop; the demos and the tests read them.
- **BRDF table (task T6.2).** A 64 by 64 `Texture2D` in `SurfaceFormat.Vector2` (two 32-bit floats, no mips), computed once on the CPU by numerical integration (1024 Hammersley-style samples per texel, GGX importance sampling with `alpha = roughness^2`, Smith geometry term with `k = alpha / 2`, `N = V = R`, after Karis, "Real Shading in Unreal Engine 4", 2013) when the first generation runs. Axes: `u` (x, columns) is `NoV`, `v` (y, rows) is the perceptual roughness, texel `i` holding the centre of its cell `(i + 0.5) / 64`, so a shader reads it at `(NoV, roughness)` without a remap; row 0 is the smallest roughness. Channel x is the scale `A`, channel y the bias `B`: the specular term is `F0 * A + B`. The sampler is linear and clamped. Measured integration time in a Debug build, cold: about 0.3 s once (alert threshold 500 ms). Limit: at a grazing angle (`NoV` below about 0.3) `A + B` rises by about 0.016 around roughness 0.4 to 0.55 before falling again, which the 65536-sample reference reproduces; it is a property of the single-scatter integral, not of the sampling.
- **Ambient of `LitPbr` (task T6.3).** `ComputePbrAmbient` returns two parts (diffuse, specular) so that a transparent surface scales only the diffuse one. With `HasIbl` at 0 (no source cube, no generated textures yet, no cache) it is the flat ambient of phase 3, unchanged (`ComputePbrFlatAmbient`). With `HasIbl` at 1: `diffuse = irradiance * EnvironmentAmbientColor * occlusion * diffuseAlbedo` (the irradiance cube holds `E / pi`, so no further division; with `UseFlatAmbientSource` the flat ambient colour replaces `irradiance * EnvironmentAmbientColor`, ADR-0098) and `specular = prefiltered(R, roughness) * (F0 * A + B) * EnvironmentSpecularIntensity * occlusion`, `R = reflect(-V, N)`, `A` and `B` read from the BRDF table at `(NoV, roughness)` kept half a texel inside the table. The roughness read by the IBL is the one the material gives (`PbrSurface.PerceptualRoughness`), not the value raised to 0.045 for the GGX of the lights, so a mirror reads band 0.
- **Texture slots of `LitPbr`.** `t9` irradiance cube, `t10` prefiltered atlas, `t11` BRDF table (12 of the 16 samplers of the target); `t12` and `t13` take the prefiltered atlases of the local probes (T7.1, 14 of 16 samplers). The atlas and the table are read with explicit clamps of their coordinates (half a texel of a 256-row band, half a texel of the table), so the result does not depend on the address mode of the sampler slot (the engine sets none for these slots).
- **Reading the atlas in the shader.** `b = roughness * 5` (the 5 is the shader constant `IblBandMax`, the number of bands minus one; never a texture size, never `LevelCount - 1`), bands `floor(b)` and `min(floor(b) + 1, 5)`, each read by `tex2D` at `(u, (band + clamp(v, 0.5/256, 1 - 0.5/256)) / 6)` with `(u, v)` the latitude-longitude mapping of `GetPanoramaUv` applied to `R`, then `lerp` by `frac(b)`. The shader never uses `texCUBElod` nor `SAMPLE_CUBEMAP_LEVEL` for the IBL (a coverage test pins it). The irradiance cube is read by the ordinary `SAMPLE_CUBEMAP`.
- **Colour space at read time.** The generated textures are linear light and are never decoded. In `LinearHdr` the shader uses the samples as they are; in `Legacy` it re-encodes them (`pow(x, 1 / 2.2)`) before combining them, to stay in the display space where that mode works. This is an approximation (the products of the split sum are formed with display-encoded factors), accepted because `Legacy` is the compatibility path; with a source that was display-encoded it gives back the source colour for a mirror (measured, task T6.3).
- **Debug constant `IblForceBaseLevel`.** A shader constant (0 by default) that forces band 0 whatever the roughness, written by `LitPbrMaterial.Bind` from the static `LitPbrMaterial.DebugForceIblBaseLevel` (not serialized, not a material property). It exists so that a measurement can show the effect of the prefiltering (the demo sets it from `CASAENGINE_COLOR_DEMO_IBL_FORCE_BASE_LEVEL=1`).
- **Measured (task T6.3, `Colour pipeline demo` with `CASAENGINE_COLOR_DEMO_IBL=1`).** A metal sphere of roughness 0 reproduces the source cube at five pixels with a mean difference of 0 levels in `LinearHdr` (Reinhard) and in `Legacy`; on a metal sphere of roughness 0.6 the contrast of the reflection on a 20-pixel line is 0.1123 prefiltered against 1.5295 with the base level forced (7.3 %). Three generations over 600 frames (the first environment plus two changes of environment), all outside the view loop.
- **Reflection probes (task T7.1).** A local reflection probe gives the PBR ambient a prefiltered specular term of its own.
  - **Atlas only.** A probe cube goes through `IblCache.TryGetPrefilteredAtlas` and is queued and flushed with the global cubes (one atlas per probe cube, generated at the start of the next frame, outside the view loop). Its irradiance is never generated: the diffuse part of the ambient stays global, a probe changes the specular term only. A cube that is first met as a probe and later used as the environment cube gets its irradiance generated then (the atlas is kept), which counts as one more generation.
  - **Linearity.** Probe cubes are generated as non-linear sources: `Lighting.fxh` decodes them as display colours in every shader, and the probe resolver has no linearity flag. A probe cube built from a `.hdr` panorama is decoded like that today in `LitForward`; `LitPbr` keeps the same assumption.
  - **Blend.** `LitPbr` computes the probe contribution like `SampleEnvironmentReflection`: the weighted mean of the (at most two) probe radiances, normalised by the sum of their weights, then `lerp(global, local, saturate(LocalReflectionProbeInfluence))`, the result going through the same split-sum term and `EnvironmentSpecularIntensity` as the global radiance. A probe whose atlas exists (`HasPrefilteredLocalReflectionProbe` and `HasPrefilteredSecondaryLocalReflectionProbe` at 1) is read by the same function as the global atlas (`SampleIblPrefiltered`, source argument 1 and 2, textures `PrefilteredLocalReflectionProbeAtlasTexture` t12 and `PrefilteredSecondaryLocalReflectionProbeAtlasTexture` t13), so the band rule, the clamps, the debug switch `IblForceBaseLevel` and the colour rule (applied once, `IblToViewSpace`) are the global ones. Until its atlas exists (the first frame in which the probe is selected) the probe is sampled unprefiltered from its cube (t4 and t5) with the decoding of `Lighting.fxh`. `LitForward` and `Lighting.fxh` are untouched and keep reading the unprefiltered cubes.
  - **Scope of the probes in `LitPbr`.** The probes act only when the global IBL is available (`HasIbl` at 1): the split-sum table that scales the specular term is bound with it, and a world that has probes but no environment cube keeps the flat ambient. Local probes refine a global environment; they do not replace it.
  - **The blend leaves the resolved-environment cache.** The resolved environment is cached per view without looking at the camera position nor at `World.ReflectionProbes.Version`, which was harmless while the probes were only sampled without prefiltering by a camera that rarely moved but is wrong for a blend that depends on the camera. When the world holds at least one probe, `EnvironmentResolver.Resolve` recomputes the probe blend on every call (the selection works on a stack buffer, nothing is allocated) and writes it over the cached value; a world without probe returns the cached value as before. Whether a probe atlas exists is not part of the cached value either: the binder asks `IblCache` at every binding, like for the global cubes.
  - **Cube supplied at run time.** `ReflectionProbe.SpecularCubemap` (a `TextureCube`, not serialized, null by default) is used before `SpecularCubemapAssetId` and `EnvironmentAssetId`, like `WorldEnvironmentSettings.SpecularEnvironmentCubemap` for the global environment. The resolver reads it from the probe collection by probe id, because the resolved-probe struct lives in a `stackalloc` buffer and cannot hold a reference; `ResolvedReflectionProbe` is unchanged.
  - **Measured (task T7.1, `Colour pipeline demo` with `CASAENGINE_COLOR_DEMO_PROBES=1`).** See the validation note of the task in `ai-agent/tasks/pbr-rendering-tasks.md`.

## Consequences

- The specular IBL costs two `tex2D` reads and one interpolation instead of one cube read with a level. It needs one more sampler than a mipped cube would, and no cube mip support from the backend.
- The prefilter is not seamless on the poles of the latitude-longitude mapping (one row of texels converges at each pole), a limit shared with the panorama path.
- The source is read at its level 0 without filtered importance sampling (a source cube has no mips), so a high-frequency source at high roughness is noisy with 64 samples. A source with mips would be read by the implicit derivative on this chain.
- If a later MonoGame honours the level of `texCUBElod`, the pinning test fails: that is the signal to reconsider a cube with mips; the atlas stays valid until then.
- The shader is decided in task T6.3 and the probes in task T7.1 (above).- A source cube is converted once per instance: replacing the cube of an environment (a new instance) generates again, and the generation of the previous one is released only when that source is disposed.
- The PBR ambient is flat for the first frame of a new environment, until the next `Render` has executed the request.
